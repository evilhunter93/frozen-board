# Frozen Board

Snowboard game where the concept is to pick up supply crates while chased by
a replicating virus.

From godot wild jam december 2025 with the following stipulations:
* Theme: Momentum
* Limitations:
    * Pocket pal
    * Frozen
    * Replicating
